# BeatFlow — Android Music Player

## Project Overview

BeatFlow is an offline Android music player being developed using Java and Android Studio for the Software Construction (SEL-311) course at Bahria University Islamabad.

## Main Features

- Browse locally stored songs, artists and albums.
- Play, pause, resume, next and previous controls.
- Favorites management.
- Shuffle and repeat functionality.
- Sleep timer.
- Background music playback.
- Notification and lock screen playback controls.
- Offline functionality.

## Technology Stack

- Java
- XML
- Android Studio
- Android SDK
- MediaPlayer
- MediaStore API
- SharedPreferences

## System Architecture

BeatFlow follows a proposed MVC-style layered architecture consisting of:

- Presentation Layer
- Application Logic Layer
- Data Access and Storage Layer
